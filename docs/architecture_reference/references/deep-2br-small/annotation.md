## Why this plan works

- At the narrowest width in this footprint family, the plan is explicit about what it can't do: no hub-lobby fits, so it doesn't attempt one and instead keeps the corridor as short as two bedrooms require. [E]
- With just two bedrooms and one bathroom, the shared bathroom sits on the direct path between them rather than at either end of a longer run it doesn't need to be. [F]
- The smallest program in the narrow-deep family keeps the footprint itself smallest too; the plan doesn't inflate massing complexity beyond what an 85 sqm program needs. [L]

## Trade-offs

- Having no room for a hub organisation at this width means this entry's ceiling on circulation-topology quality is set by the lot, not by a planning choice; a narrower lot simply can't reach the hub-parti quality tier the wider entries in this set can. [D]

## Anti-patterns avoided

- At only two bedrooms and one short direct corridor, there is no long spine to mismeasure against the compact-hub threshold in the first place, sidestepping [Hall spine without a compact hub](../../anti_patterns.md#2-hall-spine-without-a-compact-hub) by keeping the corridor short rather than by adding a hub it has no width for.
