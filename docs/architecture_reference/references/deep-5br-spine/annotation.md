## Why this plan works

- Five bedrooms are reached from one spine on the narrowest, deepest lot in the set; the plan doesn't attempt a hub or a second wing the lot width can't support, even at this program size. [O]
- Three bathrooms are spaced along the spine's length so no bedroom is more than one bathroom away, keeping wet-room reach roughly even despite the corridor's length. [F]
- Every bedroom's door opens directly onto the spine, so the corridor still reads as one continuous circulation run rather than a chain of rooms serving as the route between each other. [I]

## Trade-offs

- This is the set's most extreme spine, five bedrooms on the deepest footprint, and it is deliberately not disguised as anything else: the trade-off (long single-loaded corridor, high hall long/short aspect) is the direct, honest cost of fitting this program on this lot, not a hidden defect. [D]

## Anti-patterns avoided

- Direct spine access for every bedroom avoids [Bedroom-to-bedroom access](../../anti_patterns.md#6-bedroom-to-bedroom-access) even at five bedrooms on one corridor.
