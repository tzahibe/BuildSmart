## Why this plan works

- The ground floor uses the full plot width for the public zone, giving living/dining/kitchen one wide, contiguous volume rather than splitting the width into separate rooms. [G]
- Bedrooms upstairs are laid out across the same width, so the stair and upper landing can seat centrally on both floors instead of the upper plan needing a different footprint logic than the ground floor. [M]
- The front band gives the public zone its own street-facing exposure independent of what happens upstairs. [C]

## Trade-offs

- Carrying the same wide footprint to both floors constrains the upstairs layout to work within a width chosen for the ground-floor public zone, not for bedroom proportions, a real second-order cost of reusing one footprint across levels. [M]

## Anti-patterns avoided

- A landing that spans the same width as the ground-floor public zone below it keeps the stair's upstairs arrival point structurally and visually aligned with its ground-floor position, avoiding [Cross-level stair misalignment](../../anti_patterns.md#12-cross-level-stair-misalignment).
